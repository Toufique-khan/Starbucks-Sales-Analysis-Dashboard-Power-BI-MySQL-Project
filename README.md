# ☕ Starbucks Sales Analysis Dashboard | Power BI + MySQL Project

An interactive sales analytics dashboard built using **Power BI** and **MySQL** to analyze Starbucks sales performance, customer behavior, and revenue trends.

This project focuses on transforming raw transactional sales data into meaningful business insights through data visualization and interactive reporting.

---

# 🚀 Project Overview

The goal of this project was to:
- Analyze Starbucks sales data
- Track business performance metrics
- Understand customer behavior
- Identify peak sales hours
- Build an interactive and visually appealing dashboard
- Practice real-world business analytics using Power BI and MySQL

The dashboard was designed with multiple interactive views to provide a better analytical experience and improve decision-making.
